
# Описание проекта
Проект разработан с целью проведения ***UI*** и ***API*** тестирования сервиса по заказам авиабилетов "Авиасейлз" (https://www.aviasales.ru/)
___
## UI - тестирование
Данный раздел включает в себя следующие проверки:
+ Проверка поля "Куда" на обязательность заполнения
+ Проверка поля "Когда" на обязательность заполнения
+ Проверка автозаполнения поля "Откуда"
+ Проверка автозаполнения поля "Куда"
+ Проверка вывода результатов с помощью кнопки "Найти билеты"

Все проверки расположены в файле _test_ui.py_. Класс с методами расположен в файле _object_ui_, в директории Object. Загрузка драйвера вынесена в фикстуру файла _conftest.py_ 
___
## API - тестирование
Данный раздел включает в себя следующие проверки:
+ Проверка ненулевой стоимости билета
+ Проверка перелета по городам России
+ Проверка перелета по городам зарубежья
+ Проверка возможности просмотра стоимости билетов за прошедшую неделю
+ Проверка поиска билетов без даты отправления 

Все проверки расположены в файле test_api.py.
___
## Как запустить тесты:
+ Перейти в директорию с распложенными тест-файлами с помощью команды СD (путь до директории с файлами)
+ Запустить команду ***pytest -v (имя файла)*** для отдельного файла или Нажать кнопку ***run*** в интерфейсе Pycharm
+ Запустить команду ***pytest*** для всех тестов в директории
+ Для запуска каждого теста отдельно pytest имеет кнопку ***Run test***
